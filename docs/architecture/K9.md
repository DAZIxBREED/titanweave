# K9 — Vaultforge

K9 adds Titanweave's native archive and package substrate on top of K8 Wayfinder.

## Implemented source contracts

- `archive.rs`: 7-Zip-compatible format registry, signature probing, path traversal protection, and archive-bomb limits.
- `archive_service.rs`: versioned kernel/user archive-job contract and bounded queue.
- `package.rs`: signed/checksummed transactional package state machine with mandatory rollback preparation.
- `ARCHIVE.ELF`: initial user-space Titan Archive Service process.
- `.7z` is the preferred generic archive and package container.
- Package extensions are reserved for `.twpack`, `.twapp`, `.twdriver`, `.twupdate`, `.twtheme`, `.twfirmware`, and `.twbackup`.

## Format policy

Create and extract: 7z, XZ, BZIP2, GZIP, TAR, ZIP, WIM.

Extract/inspect through the future full codec adapter: APFS, AR, ARJ, CAB, CHM, CPIO, CramFS, DMG, EXT, FAT, GPT, HFS, IHEX, ISO, LZH, LZMA, MBR, MSI, NSIS, NTFS, QCOW2, RAR, RPM, SquashFS, UDF, UEFI, VDI, VHD, VHDX, VMDK, XAR, Z.

RAR creation is deliberately not claimed.

## Important implementation boundary

The kernel performs validation, policy, queueing, volume access control, and transaction enforcement. Heavy codecs run in the restricted user-space Titan Archive Service. This avoids putting complex decompression parsers in kernel privilege.
