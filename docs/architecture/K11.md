# K11 — ForgeBus

K11 establishes Titanweave's permanent device and driver boundary.

## Implemented contracts

- Stable device IDs, parent relationships, resources, generations, and lifecycle states.
- Full legacy PCI configuration-space enumeration including multifunction devices.
- BAR, class, revision, programming-interface, and interrupt discovery.
- Signed driver descriptors with specificity-based matching.
- Aegis policy: kernel drivers require System or Platform trust.
- Userspace-driver preference and persistent `DRIVERD.ELF` host.
- Driver crash accounting, restart limits, device unbinding, and quarantine.
- Per-device DMA domains, masks, direction tracking, revocation, and frame reclamation.
- IOMMU backend contract and secure external-device policy.
- Interrupt vector ownership and release.
- Generation-safe hot-plug event journal.
- NVMe controller validation and bounded LBA requests.
- USB HID boot-keyboard report validation and key transition decoding.

## Hardware backend boundary

ForgeBus does not invent a fake IOMMU or USB host controller. AMD-Vi, Intel VT-d, xHCI, and full NVMe queue submission are backend implementations of the K11 contracts and must be qualified on their target hardware. Devices without a policy-approved DMA domain may not be authorized for unrestricted DMA.
