# WeaveCore K6 Architecture Note

## Purpose

K6 proves that Titanweave can load several independently linked user ELF
images, schedule them, block and wake them through capability-checked IPC, and
contain a user fault without taking down WeaveCore.

## Boot modules

The UEFI loader copies `INIT.ELF`, `ECHO.ELF`, and `FAULT.ELF` into loader-owned
pages below 4 GiB. Boot protocol v6 passes fixed descriptors containing name,
type, physical address, and byte size. WeaveCore treats these as immutable boot
modules and performs its own ELF validation.

## User address spaces

Each process receives a private PML4. Supervisor-only bootstrap and higher-half
kernel mappings are copied from the kernel root, while user mappings live in
PML4 slot 2. ELF segment permissions drive writable and executable page flags.
EFER.NXE is enabled before user mappings are activated, and user stacks are
mapped writable but non-executable.

## Scheduling

Every process owns a kernel stack containing its saved `UserTrapFrame`. Timer,
syscall, and exception stubs can return a different frame pointer. Before
returning through `iretq`, WeaveCore switches CR3 and updates the CPU TSS RSP0
to the selected process's kernel stack.

## IPC and capability transfer

K6 contains one paired channel with one bounded inbox per endpoint. Empty
receive blocks the process and stores the destination buffer as a pending
operation. A later send copies the message into the blocked process's physical
pages, allocates any transferred capability in its handle table, completes the
saved syscall return value, and marks the process ready.

Capabilities are descriptors, not kernel pointers. Transfer requires the
source handle's transfer right, and the delegated rights must be a subset of
the source rights.

## Fault containment

Fatal ring-3 exceptions mark only the current process faulted. The exception
stub asks the process scheduler for another saved frame and returns there.
Fatal ring-0 exceptions still stop the machine because K6 has no safe kernel
recovery domain yet.
