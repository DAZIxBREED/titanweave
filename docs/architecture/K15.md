# K15 Architecture — ForgeAudio

K15 is Titanweave's native professional audio subsystem and is locked to the 16 gates in `K15_STONE_CONTRACT.md`.

## K15.1 scheduler foundation

The kernel scheduler now has two execution classes: `Normal` and `RealtimeAudio`. RT tasks are admitted only with explicit period, budget, deadline, priority and CPU affinity. A ForgeAudio CPU must be reserved before an RT audio task can be created.

At each RT scheduler tick, due jobs are released, absolute deadlines are computed, execution budgets are decremented and exhausted jobs are suspended until the next period. Eligible RT tasks outrank normal work. Among RT tasks, higher effective priority wins; equal-priority work uses the earlier absolute deadline.

Priority inversion is handled by `RtMutex`: waiters block, the owner inherits the highest waiter priority, and unlock transfers ownership directly to the highest-priority waiter. This is distinct from `SpinLock`, which remains the short interrupt-safe primitive.

A bounded preemption guard can defer timer-driven scheduling only for an explicitly limited number of RT ticks. The scheduler records deferrals and forcibly drops an overrun guard.

K15.1 does not yet expose the audio ABI or touch audio hardware. Those responsibilities begin at K15.2 and K15.3/K15.4 respectively.


## K15.4 real HDA backend

K15.4 is qualified/frozen. It proves the hardware-facing HDA controller path through PCI ownership, MMIO reset, CORB/RIRB, codec/widget discovery, translated BDL/data DMA, MSI-driven playback/capture completion, capture mutation, endpoint registration and peer-DMA/GPU coexistence. QEMU evidence is hardware-model evidence, not physical motherboard silicon evidence.

## K15.5 PCM format engine

K15.5 is the backend-neutral format layer above the frozen HDA/DMA path. It defines canonical S16, S24-in-32, S32 and F32 sample/container formats without changing ForgeAudio ABI v1; explicit channel-position maps; bounded interleaved/planar memory transforms; channel remapping by named position with zero-fill for absent channels and no mixing; canonical supported-rate masks; exact/nearest negotiation; HDA PCM stream-format encode/decode; and exact period/ring byte geometry within K15.3 limits.

K15.5 does not resample, mix, apply gains, or own userspace routing. Those remain assigned to later locked gates.
