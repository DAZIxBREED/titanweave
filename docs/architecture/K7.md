# Titanweave K7 — Ironroot

K7 extends the K6 disk-backed userspace proof into the first boot and storage
policy milestone. The implementation deliberately keeps K6's loader-resident
FAT32 image as a recovery mirror while introducing the interfaces required for
GPT disks, NTFS system volumes, automatic volume classification, TitanCache,
and failed-boot recovery.

## Implemented source foundations

- GPT header and partition-entry validation.
- FAT32, NTFS, and exFAT boot-sector probing.
- NTFS geometry validation and mandatory read-only safety policy.
- Whole-volume fallback when the bootstrap image is not GPT-partitioned.
- K7 volume report with filesystem and mount policy.
- TitanCache RAM budget policy with write-back disabled by default.
- Boot-health and recovery state interface.
- Preserved K6 FAT32 VFS and disk-backed service launch.

## Storage policy

- UEFI boot media remains FAT32.
- NTFS is the default future system/data filesystem.
- exFAT is supported for removable and portable storage.
- Unknown or malformed filesystems are quarantined, never formatted.
- NTFS remains read-only until MFT, journal, dirty-volume, hibernation, and
  power-loss tests are complete.
