# Titanweave K8 — Wayfinder

K8 converts K7 partition and filesystem probing into a bounded no-std automatic mount registry. GPT entries become partition block-device views, each view receives a stable GUID identity, role, trust class, filesystem classification, and mount policy.

## Safety order

1. Discover the physical or bootstrap device.
2. Validate GPT and enumerate bounded partition records.
3. Create range-checked partition block views.
4. Classify EFI, recovery, system, data, and removable roles.
5. Probe supported filesystems.
6. Apply hidden, read-only, read-write, locked, or quarantine policy.
7. Publish mount records and volume events for K9 and K10 consumers.

Unknown media is never formatted automatically. EFI and recovery volumes are internally available but hidden from ordinary applications. NTFS remains read-only until its dirty-volume, hibernation, journal replay, and power-loss requirements are implemented and qualified.
